# Smartgrow Infotech – FDE program site (clone of sde2fde.in layout)

Static site, no build step. Files: `site/index.html`, `site/styles.css`, `site/app.js`.

Run locally:  `cd site && python -m http.server 8080`  → http://localhost:8080

Before publishing edit `CONFIG` at the top of `site/app.js` (WhatsApp number, Instagram URL) and replace the
`[Placeholder]` mentor text in `index.html` / `app.js`.
