# Smartgrow Infotech – FDE Program Site

React + Vite single-page site.

```
npm install
npm run dev       # http://localhost:5173
npm run build     # outputs dist/
```

Contact links (WhatsApp / Instagram) are set in `src/data/content.js` (`CONFIG`).

## Deploy on Vercel
Import the repo, keep the detected **Vite** preset, and deploy.
